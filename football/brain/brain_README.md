# brain/ · 战术推理层

把「结构化分析」翻译成人话：**当前攻防态势**、**球可能的发展**、战术问答。
（不涉及球队识别与阵型命名。）

| 文件 | 职责 |
|---|---|
| `llm.py` | 本机 Ollama 客户端（`urllib` + `ProxyHandler({})` 禁代理） |
| `prompts.py` | 系统人设 + 「画面简报」渲染 + 解读/问答的提示词模板 |
| `analyst.py` | 对外两个函数：`advise()` / `answer()` |
| `__init__.py` | 暴露接口 |

## 关键设计

- **模型不直接看 JSON**：`prompts.brief()` 把分析结果渲染成一段自然语言「画面简报」再喂给它
  —— 更稳、更省 token，也避免模型被一堆坐标带偏。
- **只让模型干两件事**：判当前攻防态势、推演球可能的发展。
  明确要求**不要硬套 4-3-3 之类阵型名**。
- **判定权锁在系统手里**：简报里的「攻防判定」由 `vision/` 算出，提示词要求模型**直接采用**
  （判为相持就按相持写，不许自行改判），避免模型从人数分布里"脑补"出进攻方。
- **人设克制**：说具体可执行的方向；看不清就明说「不确定」，**不许编造球员号码/姓名**。
- **只用本地模型**：与任务四同款 `qwen2.5:7b`，全程离线。

## 对外接口

```python
from brain import advise, answer
print(advise(analysis))                                  # 态势 + 球的发展 两段
print(answer("球接下来最可能往哪走？", analysis, history))
```

`advise` / `answer` 内部已兜底：Ollama 没启动时返回可读的失败提示，不会抛异常中断前端。
